# SZ Direct Lab — тестовая посадочная страница

Статический сайт для GitHub Pages, созданный для проверки целей Яндекс Метрики перед подключением SZ Direct Automation к Директ API.

## Состав

- `index.html` — интерфейс страницы.
- `styles.css` — оформление.
- `config.js` — **публичный номер счётчика** Метрики (по умолчанию 0).
- `app.js` — кнопки, демоформа, лог событий, добровольное включение счётчика.
- `.nojekyll`, `robots.txt` — вспомогательные файлы.

## Размещение на GitHub Pages

1. На github.com нажмите **New repository** и назовите его `sz-direct-lab`.
2. Выберите **Public** (для GitHub Free). Нельзя выкладывать реальные токены и пароли.
3. Нажмите **Create repository**.
4. Откройте репозиторий → **Add file → Upload files**. Загрузите **файлы из архива**, а не сам ZIP. Убедитесь, что `index.html` лежит в корне, и нажмите **Commit changes**.
5. Откройте **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: main → Folder: /(root) → Save**.
6. Сайт появится по адресу `https://ВАШ-ЛОГИН.github.io/sz-direct-lab/`. GitHub Pages иногда обновляется с задержкой.

**Примечание:** в веб-интерфейсе GitHub скрытые файлы вроде `.nojekyll` можно загрузить отдельно; для этого проекта они необязательны.

## Подключение Метрики

1. На [metrika.yandex.ru](https://metrika.yandex.ru/) создайте счётчик для URL опубликованного сайта.
2. В файле `config.js` замените `0` на **числовой ID счётчика**: `window.SZ_METRIKA_COUNTER_ID = 12345678;`.
3. Commit изменений в GitHub. Обновите страницу.
4. Нажмите **«Включить Метрику на этой странице»** (до этого момента сайт не загружает трекер).
5. В Метрике откройте **Цели → Добавить цель → Целевое событие** и создайте **две** цели с точными идентификаторами:
   - `sz_test_button`
   - `sz_test_form`
6. Вернитесь на страницу и нажмите **«Отправить тестовое событие»** или **«Проверить форму»**. Страница вызовет `ym(ID, 'reachGoal', 'sz_test_button')` / `ym(ID, 'reachGoal', 'sz_test_form')`.
7. Проверьте поступление событий и работу счётчика в Метрике. Вызов `reachGoal` в интерфейсе ещё не доказывает, что данные дошли: сетевые блокировщики могут помешать.

## Важно

- Это **тестовый сайт**, не настоящая посадочная страница для рекламных клиентов и не сбор лидов.
- Не вводите на странице настоящие персональные данные. Демо-форма не пересылает содержимое на сервер.
- Отключайте рекламу и не используйте тестовые цели как оплачиваемые конверсии в реальных кампаниях.
- Никогда не храните здесь OAuth-токены API, пароли или ключи. Публичный `config.js` предназначен только для номера счётчика Метрики.
- Если хотите видеть собственные события, не исключайте тестовые посещения фильтрами Метрики.
